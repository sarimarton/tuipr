# @sarimarton/tuigh

Alias of [**tuipr**](https://github.com/sarimarton/tuipr) — a terminal review
workstation for agent-generated pull requests. Installing this package installs
tuipr and exposes it as the five-character command `tuigh`.

Why scoped: the bare name `tuigh` cannot be registered by anyone — npm rejects
it as too similar to `twig`. Note that installing plain
[`tuipr`](https://www.npmjs.com/package/tuipr) also provides the `tuigh`
command; this package is a discoverable pointer.

One product, one source of truth: all code, issues and releases live in
[sarimarton/tuipr](https://github.com/sarimarton/tuipr).
